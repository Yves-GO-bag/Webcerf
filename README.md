## Project Overview

**WebCerf** is a company website built to showcase:

- Services offered:
  - Website Creation
  - Website Redesign
  - Website Maintenance
  - Hosting
  - Basic SEO  
- Portfolio of past projects  
- Company information  
- Contact methods including phone, email, and a contact form  

The website is fully responsive and mobile-friendly, featuring a hamburger navigation menu, smooth scrolling between sections, and professional visuals.

---

## Features

- Fully responsive design for desktop and mobile devices  
- Hero sections on Home, Services, and Contact pages  
- Smooth scrolling navigation for services  
- Interactive hamburger menu for mobile view  
- Contact section with embedded Google Maps  
- Contact form integrated with Formspree for easy submissions  
- SEO-friendly meta tags and Open Graph integration  
- Google Fonts integration: Poppins & Roboto  
- Clear calls-to-action: Book Us, Call, Email  

---

## Technologies Used

- **HTML5** – Structured content for all pages  
- **CSS3** – Styling for layout, responsiveness, and media queries  
- **JavaScript** – Interactive features like hamburger menu toggle and form validation  
- **Google Fonts** – Poppins & Roboto for typography  
- **Formspree** – Backend-free contact form submissions  
- **Google Maps Embed** – Interactive map on Contact page
